DexMimicAnything

Learning Generalizable In-Hand Skills from Human Demonstrations

One reactive hand–object co-tracking controller. It learns in-hand rotation, translation, and regrasping from human demonstrations on 34 primitive shapes, and runs zero-shot on unseen tools.

01 / Motivation

Complex in-hand manipulation is difficult with direct teleoperation.

Real robot, 1.0×. In both columns the operator handles one copy of the tool and the robot handles a second copy.

02 / Real-robot demos

One frozen policy performs single in-hand motions, tool-use tasks, and multi-tool sequences.

1Primitive in-hand skills 2Tool use with unseen tools 3Several tools in one run

Level 1 Primitive in-hand skills

Rotate, translate, and reorient an object inside the hand

These are the building blocks. The objects are the kind of geometric primitives the policy is trained on, and the fingers do the work while the arm follows the reference wrist.

Level 2 Tool use with unseen tools

The primitives combine into complete tool-use tasks

None of these tools appear in training. Each task chains a grasp, in-hand adjustments, and a functional action. The reference comes either from a recorded human demonstration or from a live operator.

Level 3 Several tools in one run

Two tools, one continuous teleoperated run

The operator finishes one task, puts the tool down, and picks up the next. The policy is not reset in between.
